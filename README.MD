# CUBEFLICT

Juego de estrategia narrativa: eres embajador ante el Consejo de Seguridad
de la ONU y tienes 15 turnos para evitar una guerra. Combina match-3 con
decisiones diplomáticas, vetos de los cinco miembros permanentes y finales
inspirados en resoluciones reales de la ONU.

## Jugar
Abre `index.html` en el navegador. No requiere instalación.

## Simulación de balance
`node bot.js 1000 both` — corre 1000 partidas en modo smart y random
y compara resultados. Verifica que el balance sigue sano.

## Stack
HTML + CSS + JavaScript vanilla. Web Audio API para sonido procedural.
localStorage para autoguardado. Sin dependencias.
